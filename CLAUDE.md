# WH Briefing Shorts Factory

## Project Overview
Autonomous pipeline that transforms White House briefing transcripts into viral YouTube Shorts for Korean learners of English. Three Claude Code subagents (Analyst, Director, Engineer) orchestrate the full workflow from transcript extraction to final rendered video.

## Architecture
- **Pipeline**: Source Video → Transcript → Language Analysis → Content Production → Remotion Render → QA → Export
- **Agents**: `.claude/agents/analyst.md`, `.claude/agents/director.md`, `.claude/agents/engineer.md`
- **Rendering**: Remotion (primary), FFmpeg (fallback/MVP)
- **Storage**: Supabase + pgvector for semantic search, `vector_cache.json` as offline fallback

## Performance Profiles
Set via `PERFORMANCE_MODE` env var:
- **LOW** (Chromebook): `MAX_CONCURRENCY=1`, Haiku model, 30s sleep between renders, single-core
- **HIGH** (Desktop/CI): Parallel rendering, Sonnet model, all CPU cores

## Branding & Design Rules
- Aspect ratio: **9:16** (vertical Shorts)
- Captions: max **2 lines**, max **42 chars** per line, EN + KR bilingual
- Font: to be defined in `src/styles/theme.ts`
- Hook segments: accent color highlight
- Wrap-up segments: CTA banner overlay
- Keyword highlights: dynamic color per expression

## Key File Conventions
- `src/data.ts` — per-render data file generated by Director agent (strict audio-caption timing sync)
- `src/styles/theme.ts` — isolated theme config (fonts, colors, safe zones); editable without touching render logic
- `clips.json` — intermediate clip definitions from analysis pipeline
- `expressions_grouped.json` — grouped linguistic expressions (sets of 5)
- `qa_report.json` — QA validation output per part

## Development Commands
```bash
# Install dependencies
npm install

# Preview in browser
npx remotion studio

# Render a single composition
npx remotion render src/index.ts MainComposition out/video.mp4

# Render with LOW profile
PERFORMANCE_MODE=LOW npx remotion render src/index.ts MainComposition out/video.mp4
```

## Rules for Agents
1. Always read `src/styles/theme.ts` before modifying any visual component.
2. Never hardcode timestamps — all timing must flow from `data.ts`.
3. On render failure, parse `stderr` and attempt auto-fix (font-missing → patch theme, line-break → patch data) up to 3 retries.
4. QA validation must pass before any render is considered "done."
5. Each Short must be ≤ 180 seconds.
6. Subtitle text: max 2 lines, max 42 chars/line. Auto line-break if exceeded.
7. When creating multiple shorts from one video, ensure no temporal overlap between clips.

## Environment Variables
See `.env.example`:
- `PERFORMANCE_MODE` — `LOW` or `HIGH`
- `SUPABASE_URL` — Supabase project URL
- `SUPABASE_ANON_KEY` — Supabase anonymous key
- `REMOTION_CPU_CORES` — number of cores for parallel rendering
- `YT_VIDEO_URL` — target YouTube video URL (single video only; playlist params like `&list=` are stripped via `--no-playlist`)
