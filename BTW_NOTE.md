# BTW Notes

## 3-Pass Listening Pattern

Each expression in a Short uses a 3-pass repetition pattern for effective language retention:

1. **Raw** — Play the original clip as-is (learner hears the expression naturally)
2. **Blank out** — Replay with the key expression blanked/muted (learner tries to recall — cloze deletion)
3. **Full reveal** — Show the expression highlighted with definition + Korean explanation
